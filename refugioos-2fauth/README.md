# 2FAuth — tienda UmbrelOS (RefugioOS)

App del Community App Store de RefugioOS para umbrelOS.

- Imagen: `ghcr.io/refugioos/2fauth:8.0.2-refugioos.1`
- Web: puerto 3482 (proxy interno 8000)
- Datos: `${APP_DATA_DIR}/data` -> `/2fauth`

Ficha y port: `2fauth-umbrel/` en el workspace. Update:
`update-2fauth.py`. Publicacion: `deploy-port.py` + `publicar-app.py --app 2fauth`.
